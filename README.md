# CG Enterprises — Editorial Gold

Approved bright editorial website with ivory, charcoal, and metallic-gold accents. Next.js App Router. The existing Wix site stays live until migration is approved.

## Build

```bash
npm install
npm run dev
npm run build
```

## Before launch

Replace editorial placeholder photos, verify corporate contact address, implement secure form delivery and CRM, populate verified Etsy product links, verify redirects and domain access, test accessibility and mobile presentation.
